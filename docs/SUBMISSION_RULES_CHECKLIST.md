# Codegeist 2026 — official eligibility/submission checklist

Primary authoritative source: https://codegeist2026.devpost.com/rules
Challenge home: https://codegeist2026.devpost.com/
**Verified 2026-11-24.** Official rules override summaries if changed. Actual owner Devpost account status remains UNVERIFIED.

## Registration and legal
- [ ] Eligible entrant (age of majority; location and employment/exclusion clauses) verified by owner.
- [ ] Devpost joined/registered; actual status checked.
- [ ] All reused source/assets, AI outputs, graphics, voices and libraries legally used; license/NOTICE.
- [ ] No personal/customer confidential data or unauthorized licenses in public demo.
- [ ] Team members/ownership and participation details correct; no paid purchase required.

## Functional program
- [ ] Working Forge app with manifest.yml and at least one integrated Atlassian product: Jira required by our design.
- [ ] At least one legitimate Forge module integrated and can be independently installed by judges.
- [ ] App install/share link and environment/setup steps verified on clean site.
- [ ] Actual app behavior replicates narrated video, no screenshots as substitute.
- [ ] Third-party deployment/privacy and permissions/Forge terms respected.

## Devpost submission
- [ ] Relevant category selected (Software Teams suggested; not locked).
- [ ] English text or English translation with problem, functionality, innovation, technology, Atlassian tie-in.
- [ ] Install link + detailed setup/testing instructions, example workflow and any necessary demo config.
- [ ] Public YouTube demonstration shorter than five minutes, actual working app visible.
- [ ] Accurate screenshots/diagram and measured claims; optional PDF is NOT mandatory.
- [ ] Bonus category material only if eligible modules/API integrated and verified.
- [ ] Published within deadline, exact Devpost URL / timestamp recorded, owner final GO.

## Dates
Registration/submission: 2026-10-27 09:00 PT to 2026-12-22 12:00 PST.
Deadline Korean local: 2026-12-23 05:00 KST.
Official judging: 2027-01-05 13:00 PT to 2027-02-03 17:00 PT; winners on/about 2027-02-15 09:00 PT.

## Scoring
Qualified entries are evaluated on Technology, Design, Potential Impact, Innovation, Presentation (20% each). A feature must be more than a Jira Automation duplicate to stand out. No win probability forecast is evidence.

## Bonus / scope boundaries
Bonus variants include use of Forge Rovo/agent-related modules, Atlassian MCP, Teamwork Graph integration and Marketplace criteria. Exact module/eligibility details must be reconfirmed from official current rules before pursuing; no unverified bonus claims.
Marketplace listing/approval or production external distribution may be separately risky and requires owner GO. Forge runtime pricing and LLM API billing must be checked, not inferred from free hackathon entry.
